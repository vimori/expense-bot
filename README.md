# Учёт трат — Telegram-бот

Минималистичный бот для ежедневных расходов: запись в пару касаний,
автоматизации для частых трат и анализ с советами, которые не требуют
отказываться от привычек.

## Возможности

- **Новая трата** — выбор категории, затем готовая автоматизация или своя сумма.
- **Автоматизации** — например, «Автобус · 1,05 ₽» и «Маршрутка · 2 ₽»
  создаются сразу. Добавляйте свои: название, категория, сумма.
- **Анализ трат** — за сегодня, неделю и месяц: сумма, число трат,
  средний расход в день, сравнение с прошлым периодом и разбивка по категориям.
- **Советы** — бот сам находит зоны роста (транспорт, кофе, доставка, подписки)
  и предлагает мягкую оптимизацию с ориентиром экономии.
- **Удобные мелочи** — повтор траты одним нажатием, отмена только что
  записанной траты, редактирование одного сообщения вместо десятков новых.

## Запуск

1. Получите токен у [@BotFather](https://t.me/BotFather) (`/newbot`).
2. Установите зависимости:

   ```powershell
   pip install -r requirements.txt
   ```

3. Создайте `.env` рядом с `bot.py`:

   ```env
   BOT_TOKEN=123456789:ВАШ_ТОКЕН
   TIMEZONE=Europe/Moscow
   ```

   Можно скопировать `.env.example` и вписать токен.

4. Запустите:

   ```powershell
   python bot.py
   ```

База создаётся автоматически в `data/bot.db`.

## Структура

```
bot.py               запуск, диспетчер, команды
config.py            токен, часовой пояс, путь к базе
categories.py        категории и автоматизации по умолчанию
db.py                SQLite: пользователи, траты, автоматизации
keyboards.py         инлайн-клавиатуры
texts.py             статические тексты
stats.py             подсчёт периодов, отчёт, советы
ui.py                форматирование денег, дат, безопасное редактирование
middlewares.py       пользователь из базы в каждом обработчике
handlers/            сценарии: траты, анализ, автоматизации, меню
```

## Настройка

- Часовой пояс задаётся в `.env` (`TIMEZONE`), по умолчанию `Europe/Moscow` —
  от него зависят границы дня, недели и месяца.
- Автоматизации по умолчанию меняются в `categories.py` (`DEFAULT_PRESETS`).
  Суммы там указаны в копейках.
- Свои автоматизации и траты хранятся в SQLite, их можно добавлять и удалять
  прямо в боте.

## Хостинг

Бот работает круглосуточно на бесплатном тарифе [Altare](https://altare.gg)
(сервер `expense-bot`, шаблон «Python app», 512 МБ RAM, 3 ГБ диска, Швеция).
Ноутбук держать включённым не нужно.

- Код берётся из этого репозитория: при запуске сервер скачивает архив
  коммита, создаёт виртуальное окружение и ставит `requirements.txt`,
  затем выполняет `python bot.py`.
- Переменные окружения (`BOT_TOKEN`, `DB_PATH`, `TIMEZONE`) хранятся в
  настройках запуска сервера, а не в репозитории.
- База лежит в `/home/container/data/bot.db` — вне папки с кодом, поэтому
  переживает перезапуски и деплои.
- Консоль и логи: https://console.altare.gg/server/ed34e7f5-8c08-4eb5-b242-35789d73f1ad

### Обновить код на сервере

```powershell
git add -A
git commit -m "Что изменилось"
git push
```

Затем в консоли Altare на странице сервера нажать **Reinstall / Start**
или обновить переменную `GIT_COMMIT` на новый хеш (`git rev-parse HEAD`)
и перезапустить сервер. Папка `data/` при этом не затрагивается.

Локальный запуск для разработки остаётся прежним (`python bot.py`), но
одновременно с сервером его запускать нельзя: Telegram отдаёт обновления
только одному экземпляру и второй падает с `TelegramConflictError`.
